**Curso:** Tecnólogo em Análise e Desenvolvimento de Sistemas  
**Carga Horária:** 60 h/r (3 horas por semana)

---

# Objetivo Geral

Desenvolver um sistema web utilizando as linguagens de programação **Java** e **JavaScript**, juntamente com os frameworks **Spring Boot** e **React.js**.

---

# Objetivos Específicos

- Compreender e utilizar arquiteturas de software adequadas;
- Conhecer e configurar ferramentas para o ambiente de desenvolvimento e implantação na linguagem Java;
- Construir soluções de software para o ambiente web utilizando padrões de projeto;
- Discutir arquitetura de software e técnicas de distribuição;
- Utilizar frameworks para comunicação com banco de dados;
- Utilizar frameworks baseados nas arquiteturas **MVVM** e **SPA**.

---

# Conteúdo Programático

## Primeira Unidade

- Introdução a Sistemas Web;
- APIs REST;
- Configuração do ambiente de desenvolvimento;
- Controle e versionamento do projeto com Git;
- Criação do projeto (Back-end e Front-end);
- Arquitetura do projeto (Back-end e Front-end);
- Implementação do CRUD:
  - Cadastro;
  - Listagem;
  - Consulta por ID;
  - Alteração;
  - Remoção;
- Validações no Back-end.

---

## Segunda Unidade

- Relacionamento entre entidades;
- Documentação da API com Swagger;
- Geração de relatórios em PDF;
- Implementação de filtros de pesquisa;
- Envio de e-mails utilizando templates Thymeleaf;
- Controle de acesso:
  - Autenticação;
  - Autorização;
  - Auditoria;
- Configuração de dados do ambiente em arquivos locais;
- Deploy da aplicação no servidor.
